# Guide to Contributing

Keep PRs small, simple and about one thing.

PRs with more than a few dozen or hundred lines of code are very unlikely to be merged. When in doubt, please first open an 
issue to have a discussion about it.

Pull requests generated by LLMs will be rejected. You are free to use LLMs in your own workspace to explore a problem,
but any code you submit must be written by you, not the LLM. Do not submit PRs with LLM generated descriptions, they
create walls of text that are mostly waffle and nonsense and a waste of everyone's time.
